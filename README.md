One haiku about debugging, written for the [Seventeen Syllables of Debugging](https://make.fun/c/u-irvan-motion-seventeen-syllables-of-debugging-d194b605) competition on [make.fun](https://make.fun).

## The haiku

> Breakpoint holds its breath
> the stack unwinds past midnight
> one semicolon

Three lines in the 5-7-5 syllable shape, 73 characters total. A concrete debugging
image — a breakpoint, a stack unwinding past midnight — and a last line that turns
the whole night on a single semicolon.

## How it works

`main.py` (pure Python standard library, no dependencies, no network) writes the
haiku to `/output/entry.txt`.

```sh
python3 main.py
cat /output/entry.txt
```
